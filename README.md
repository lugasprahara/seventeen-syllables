One haiku about debugging, in the 5-7-5 shape: "Cursor blinks at three / the final log line just says / segfault — then silence". Seventeen syllables on the night shift: a cursor still blinking at 3 a.m., a log that has run out of things to tell you, and a last line that turns out to be the crash itself. The program in `main.ts` writes those three lines to `/output/entry.txt`, checking the 5-7-5 syllable shape and the 200-character gate before it ships, and that text is the whole entry.

## Run it

```sh
node main.ts
```
